# Планер Алины

Светлый iOS-планировщик на SwiftUI: привычки, задачи сегодня и завтра, заметки, календарная неделя, статистика и виджеты трёх размеров.

## Что уже работает

- добавление и выполнение привычек;
- отметки привычек по датам;
- задачи на выбранный день и на завтра;
- удаление задач свайпом;
- заметка с автоматическим локальным сохранением;
- общий контейнер данных приложения и WidgetKit;
- маленький, средний и большой виджеты.

## Открытие проекта

Проект описан в `project.yml`. На Mac установите XcodeGen (`brew install xcodegen`), выполните `xcodegen generate`, затем откройте `AlinaPlanner.xcodeproj` в Xcode. Для реального устройства выберите свою Apple Developer Team у обоих targets и замените bundle ID / App Group на уникальные значения вашей команды.

Минимальная версия: iOS 17.
